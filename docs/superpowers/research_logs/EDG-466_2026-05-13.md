## Heartbeat Outcome
Validated and fixed `other_dt0` priority escalation matching by ensuring runtime metadata carries `image_id`/`id`, then confirmed strict-probe `no` path can force full-MM escalation for targeted hard cases.

## What Changed
- `triage_sandbox.py`
  - Added `priority_sample_image_id` to `other_dt0_trace` for audit visibility.
  - Extended audit summary print for `other_dt0` to include:
    - `priority_escalation_candidate`
    - `priority_escalation_forced`
    - `priority_sample_image_id`
  - Fixed metadata ingestion (`sample_metadata_by_image`) to preserve:
    - `image_id`
    - `id`
  - This allows `sample_image_id` in `triage_fn(...)` to resolve to canonical IDs (e.g., `ASONAM2017_38`) instead of filename stems like `sample_038`.
