### `triage_sandbox.py`
- Added new prompt variant template: `SEVERE_DT0_RESCUE_GUARD_STRICT_TRIAGE_PROMPT_TEMPLATE`.
- Added resolver mapping for env toggle: `TRIAGE_MAIN_PROMPT_VARIANT=severe_dt0_rescue_guard_strict`.

New strict rules emphasize:
- severe-damage scenes default to `infrastructure_and_utility_damage` unless direct rescue delivery is visible;
- responder/crowd/vehicle presence alone cannot justify `rescue`;
- rescue requires direct aid cues (evacuation/carrying victims, stretcher transport, medical treatment, or extraction).

## Observations
- Prompt-only strict rescue gating produced a material F1 improvement while keeping latency effectively flat.
- Residual severe-`dt0` errors remain on key cases (`ASONAM2017_34`, `ASONAM2017_38`) where `full_mm` still outputs `rescue`.
- This indicates prompt tightening alone improved overall classification mix, but hard severe-corner confusion persists for some images.

## Conclusion
The strict severe-`dt0` prompt guard is a strong frontier candidate: substantial F1 gain with negligible latency cost and no extra probe burden.
