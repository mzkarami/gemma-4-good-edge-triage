# ADR-003: Current Frontier as Public Claims Source

Status: Accepted
Date: 2026-06-27

## Context

The repository contains historical EDG logs, submission drafts, and older milestone metrics. Without a precedence rule, public claims can drift.

## Decision

`docs/CURRENT_FRONTIER.md` is the canonical source for public benchmark claims. Historical logs remain evidence and audit trail, not direct public copy sources unless promoted through the frontier doc.

## Consequences

- Public metrics should link to or match `docs/CURRENT_FRONTIER.md`.
- Older metrics must be labeled historical.
- Benchmark/frontier updates should include validation evidence.
