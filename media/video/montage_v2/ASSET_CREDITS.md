# Disaster-context montage v2 asset credits

Purpose: a more immediate, ground-level 10-second public-demo opening for Edge-Triage, based on user-provided YouTube Shorts style references but using legally safer public-domain / Creative Commons footage instead of cutting from arbitrary YouTube Shorts.

Editorial guardrails:
- Respectful, non-graphic disaster context.
- No visible casualties or sensational injury/death footage.
- Short clips only, used to establish operational context before the product demo.
- Subtitles explain why each visual matters for edge triage.
- Direct reuse of the user's YouTube Shorts examples is avoided unless license/permission is clear.
