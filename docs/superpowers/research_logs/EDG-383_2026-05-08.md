# EDG-383 — Runtime Block-Dedupe + Latency-Outlier Guard Hardening

Date: 2026-05-08
Agent: Engineer (Researcher)

## Scope
Harden the autonomous optimization loop against duplicate blocked reruns and non-comparable latency spikes, while preserving edge constraints (`<4s`) and minimizing wasted retries.

## Changes Implemented

### 1) State-hash and dedupe hardening
- Switched `compute_state_hash()` from MD5 to SHA-256.
- Expanded state hash inputs to include:
  - `TRIAGE_TARGETED_PROBE_BUCKET_BUDGET`
  - `TRIAGE_ALLOW_REDUCED_GPU_BENCHMARK`
  - `TRIAGE_CPU_GUARD_MAX_SAMPLES`
  - `TRIAGE_RUNTIME_CPU_FALLBACK_MB`
  - `TRIAGE_POSTLOAD_GPU_GUARD_MIN_MB`
- Removed transient `TRIAGE_PREIMPORT_CPU_GUARD_ACTIVE` from hash inputs to avoid nondeterministic dedupe misses caused by momentary runtime conditions.
- Upgraded image hashing from first-1MB sampling to full payload chunk hashing for stable content-sensitive identity.

### 2) Results I/O efficiency and consistency
- Added run-local parsed-row cache for `results.tsv` (`_load_results_rows` + invalidation on append/schema migration).
- Reworked readers (`load_recorded_state_hashes`, `load_best_recorded_f1`, `load_best_latency_for_f1_floor`) to use parsed-row cache.
- Adjusted dedupe statuses so `blocked` rows are no longer considered equivalent to previously evaluated comparable runs.

### 3) Duplicate blocked-state suppression
- Added `has_blocked_reason_for_state_hash(...)` to short-circuit repeated blocked runs by matching recent blocked reason fragments per state hash.
- Applied this pre-load dedupe for:
  - pre-import low-VRAM CPU guard
  - CPU-only offload unavailable
  - post-load GPU telemetry unavailable
  - reduced-layer guard under persistent low VRAM
  - runtime low-VRAM CPU fallback
  - guarded CPU capped diagnostics
  - latency-outlier blocked state

### 4) Latency outlier guard (same-hash baseline)
- Added comparable-latency history lookup:
  - `load_recent_keep_latencies_for_state_hash(...)`
  - `detect_latency_outlier_for_state_hash(...)`
- New tunables:
  - `LATENCY_OUTLIER_LOOKBACK` (default 30)
  - `LATENCY_OUTLIER_MIN_SAMPLES` (default 2)
  - `LATENCY_OUTLIER_RATIO` (default 1.45)
- Behavior: if current latency exceeds `median(same-hash keep latencies) * ratio`, run is marked blocked/non-comparable and duplicate retries are suppressed.

### 5) Guarded runtime instrumentation
- Added process-scoped GPU memory telemetry (`detect_process_vram_mb`) using `nvidia-smi --query-compute-apps` to avoid counting unrelated workloads.
- Added env controls:
  - `TRIAGE_ALLOW_REDUCED_GPU_BENCHMARK`
  - `TRIAGE_RUNTIME_CPU_FALLBACK_MB`
  - `TRIAGE_POSTLOAD_GPU_GUARD_MIN_MB`
  - `TRIAGE_BLOCKED_EXIT_CODE`
- Added targeted-probe per-bucket throttle helper `consume_probe_budget(...)`.
