# Data Workspace

This directory is intentionally almost empty in the public repository.

Use it for local experiment inputs:

- `data/` for temporary QCRI/MEDIC-style `.parquet` shards or `gold_set.json` generated by `prepare.py`;
- `data/images/` for active local image extracts used by a benchmark run;
- `data/archive/` for processed local shards.

The public repo keeps only `.gitkeep` placeholders. Do not commit generated data, disaster reports, uploaded images, or large dataset/model artifacts here. Use the dataset/model links in the submission docs and local cache paths instead.
