## Problem Found After r1
- `EDG-350 r1` required `TRIAGE_ALLOW_GUARDED_CPU_BENCHMARK=1` to run on a CUDA-inactive host.
- Even with that flag, runtime still executed the full 50-sample benchmark because CPU diagnostic capping only triggered when `force_cpu_backend=True`.
- In this host condition, GPU was requested but effectively inactive (`GPU Active: False`) without entering `force_cpu_backend` path.

- Maintains existing behavior:
