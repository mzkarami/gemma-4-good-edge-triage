# EDG-359 - Edge-Triage Optimization Loop (2026-05-04)

## Wake Delta Handling
- Wake reason: `issue_assigned`
- New action: reduce repeated non-comparable run cost by short-circuiting duplicate latency-outlier blocked states before model load.

## Problem Statement
- The sandbox already re-labels severe host-variance latency spikes as:
  - `blocked: latency outlier vs same-state median ...`
- Before this change, repeating the same state hash could still pay full model load + evaluation cost before landing on the same blocked outcome.

## Code Change (r1)
Updated `triage_sandbox.py`:
- Promoted experiment signature to:
  - `edg359-r1-latv2-preload-short-circuit-duplicate-latency-outlier-blocked-nctx933-gpu47-probebudget11`
- Added a pre-load duplicate blocked-state short-circuit in `run_triage()`:
  - Checks for existing blocked row on current `state_hash` containing reason fragment:
    - `latency outlier vs same-state median`
  - On match:
    - prints duplicate blocked-state message
    - calls `cleanup_after_run()`
    - returns `{"status": "blocked", "state_hash": current_hash}`
  - This exits before `Llava15ChatHandler(...)` / `Llama(...)` initialization.
