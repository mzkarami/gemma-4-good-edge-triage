# EDG-464 - 2026-05-13

## Heartbeat Outcome
Implemented and validated a control-flow fix for `other_dt0` strict-probe routing so strict-probe `no` paths can optionally use explicit priority escalation before returning metadata shortcut, while keeping broad severe-force escalation disabled by default.

## Code Changes
- `triage_sandbox.py`
  - Added `TRIAGE_OTHER_DT0_FORCE_SEVERE_PRIORITY` (default `0`) and included it in state hash.
  - Updated `should_force_other_dt0_priority_escalation(...)` to:
    - support `image_id` token matching,
    - disable broad severe/signature forcing unless explicitly enabled.
  - Added `sample_image_id` extraction in `triage_fn(...)` and threaded it into both `should_force_other_dt0_priority_escalation(...)` call sites.
  - In strict-probe branch for `other_dt0`, strict-probe `no` now checks priority escalation before preserving metadata shortcut.
