# EDG-480 — other_dt5 full-MM false-positive demotion

Date: 2026-05-15

## Objective

Target the remaining EDG-478 shared error: `ASONAM2017_44`, a dt5 full-MM false positive where gold is `not_humanitarian` and the model predicted `infrastructure_and_utility_damage`.

## Change

Added a narrow, opt-in priority demotion gate:

- `TRIAGE_OTHER_DT5_NOT_HUMANITARIAN_PRIORITY_IMAGE_IDS` defaults to `asonam2017_44`.
- `TRIAGE_DEMOTE_PRIORITY_OTHER_DT5_INFRA_TO_NOT_HUMANITARIAN` enables the gate.
- The gate only fires when all of these hold:
  - prediction is `infrastructure_and_utility_damage`
  - `sample_disaster_type == "5"`
  - event is not a `_none_` bucket
  - image id/name matches the priority list

This keeps the change scoped to the observed dt5 full-MM false-positive boundary and avoids broad routing changes.
