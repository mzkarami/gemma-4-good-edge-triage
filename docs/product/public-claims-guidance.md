# Public Claims Guidance

Status: current copy and claims guardrail.

## Allowed claim pattern

Use `../CURRENT_FRONTIER.md` as the source of truth for F1, accuracy, latency, sample count, and profile names.

## Required framing

- Edge-Triage is decision support, not emergency authority or medical advice.
- The public static demo is curated/offline.
- Live Gemma preview is optional and guarded.
- Older metrics are historical unless repeated in `../CURRENT_FRONTIER.md`.

## Avoid

- Unsupported claims that the system replaces incident command.
- Claims that live inference is always available.
- Claims that target/future mobile/NPU deployment already exists unless implemented and verified.
- Benchmarks without sample count, profile, and source.
