# Disaster Response Guidance Pack

Status: deterministic reference pack for response shaping.

These files contain conservative Edge-Triage guidance snippets by triage family. They are not medical protocols, legal instructions, or incident-command authority. The shared core uses the same ideas as `guidance_basis` in API/CLI responses so users can see why an action pack is conservative.
